## 2. Rationale & Choice of Host
* **Chosen Host:** Vercel (Free Tier).
* **Why Vercel:** Since we selected the Next.js stack, Vercel is the native hosting platform. It provides automatic edge caching, instant Git integration, zero-config TypeScript build pipelines, and free HTTPS out of the box. 
* **Git Integration:** Every push to our main branch on `github.com/Vrishinram/portfolio` automatically triggers a fresh production build and deploys it live, ensuring our portfolio is always up-to-date with our local codebase.
