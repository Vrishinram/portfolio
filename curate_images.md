## 2. Rejection Note (Discernment & Judgment)
We generated a series of conceptual graphics for the hero section background using AI:
* **Rejected Image:** A flashy, high-contrast, neon-green cyber hacker terminal with glowing matrix code falling in the background.
* **Why Rejected:** It looked like typical "AI slop" and visual noise. The fake glowing text was illegible, the matrix rain felt like an amateur movie cliché, and the colors clashed violently with our clean dark-blue glassmorphic identity. A portfolio design must frame the work, not compete with it.
* **The Choice:** We rejected all abstract neon graphics and instead built an interactive canvas (`ImageSequenceCanvas.tsx`) showing actual, clean network topologies fading smoothly as the user scrolls. This looks highly professional, matches our color scheme, and directly proves frontend engineering capabilities.
