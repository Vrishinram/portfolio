# Decide Once: Build Your Identity Kit
**Author:** Vrishin Ram K  
**Project:** Cybersicker — Dual-Core Autonomous SOC AI Agent  

---

## 1. Typography Pairings
* **Heading Font:** `Outfit` (sans-serif, geometric, confident, and modern. Communicates precision and technical strength.)
* **Body Font:** `Inter` (sans-serif, highly legible, clean, and professional. Provides a comfortable reading experience for case studies and logs.)

## 2. Harmonious Color Palette
Our design utilizes a dark-mode theme designed to evoke the cockpit view of a modern Cybersecurity Operations Center (SOC) dashboard.
* **Background:** `#050712` (Vesper Deep Blue-Black — keeps the focus on code and telemetry.)
* **Surface/Card:** `#0c0f1d` / `rgba(15, 18, 35, 0.65)` (Translucent surface with background blur.)
* **Main Text:** `#e8ecf4` (Crisp Off-White — high contrast, gentle on eyes.)
* **Muted Text:** `#8892a7` (Slate Gray — for labels and secondary information.)
* **Accent Blue:** `#3b82f6` (System status / standard info highlight.)
* **Accent Cyan:** `#06b6d4` (Threat anomaly detected warning highlight.)
* **Accent Orange/Amber:** `#f59e0b` (High-severity beacon / C2 detection indicator.)

## 3. Monogram / Logo / Favicon
A custom minimalist geometric monogram is used:
* **Symbol:** A dual-core interlocking node pattern representing machine learning (TensorFlow autoencoder) and agentic logic (Gemini) working together.
* **Favicon:** Rendered as a secure vector shield icon (`flyrank-icon-mint.svg`) reflecting security and blue teaming operations.

## 4. Two-Line Style Note
> **Mood:** Calm, ultra-modern glassmorphic SOC cockpit. Spacing is kept generous (`--space-lg`), colors are restrained to high-contrast dark values, and micro-interactions use smooth cubic-bezier transitions (`cubic-bezier(0.16, 1, 0.3, 1)`) so the portfolio frames the cybersecurity telemetry without stealing the show.
